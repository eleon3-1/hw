# msgboard

A new Flutter project.

## Getting Started


MsgBoard is a app built with flutter and firebase. Users can create an account
sign in , post messages ans sigh out without it deleting messages or anyythng
unless the user that made the post deletes it. Messages update automatically without
refreshing. Users can edit and delete their own messages. The app includes a loading screen, checks for missing information, and prevents erorrs and exploits like double tabbing from posting the same message twice. It runs on chrome and anroid.
